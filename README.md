# Hi, I'm Jonas.

I'm Jonas Roberto de Goes Filho, a mobile developer based in Italy and the founder of **[EtiquetaChef](https://etiquetachef.com)**. My dream is to walk into a kitchen anywhere in the world and see the team using something I built.

## Building EtiquetaChef

I build software that helps professional kitchens reduce waste and control food costs. With EtiquetaChef, a cook can scan a batch’s QR label and record how much went into lunch, even in a cold room without Wi-Fi. The next shift can see what’s left, and the manager can see what was used or discarded across kitchens.

### Where I'd take the ecosystem next

- **API idea** · A restaurant's purchasing system could ask how much tomato sauce is already on hand before placing the next order.
- **Webhook idea** · When a kitchen records a discarded batch, its cost dashboard could receive the quantity and reason automatically. The chef would only enter it once.
